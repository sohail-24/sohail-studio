# Sohail Studio Documentation V2

## Project Overview

Sohail Studio is a self-contained, local-first AI engineering workspace. There is no separate CLI installation required. The project runs entirely on one Python environment (`.venv`), seamlessly integrating a dashboard, a secure AI Chat module (Phase 1), an AI Control Plane (Phase 2), a Raw PTY Terminal, and a dedicated Sohail-Agent execution CLI.

## Running the Project

- **Setup:** Run `python3 -m venv .venv` and then `.venv/bin/python -m pip install -e .` to setup the single environment. Use `.venv/bin/python -m pip install -e '.[dev]'` for test dependencies.
- **Execution:** Start the server using `.venv/bin/uvicorn backend.main:app --reload`. Access the studio via `http://127.0.0.1:8000`.
- Ollama must be running locally to process AI generations.

## Chat & AI Control Plane (Phase 1 & 2)

The Chat uses `devops-qwen:latest` strictly via local Ollama inference.

- **Phase 1 (Chat):** Normal knowledge questions are answered natively without executing local commands.
- **Phase 2 (Control Plane):** When local environment context is required, the AI Control Plane safely aggregates data using multi-tool capabilities (e.g., `pwd`, `ls`, Docker/Git/Kubernetes read-only status). It explicitly prevents execution of state-mutating commands.

## Raw PTY Terminal

The raw Terminal is a dedicated, real local PTY shell (e.g., `zsh` or `bash`). It operates completely separately from the AI Chat and Sohail-Agent workflows. The terminal automatically configures to the `.venv` context and provides unrestricted local execution capabilities.

## Sohail-Agent Workflows

Sohail-Agent acts as a separate DevOps CLI, distinct from the LLM chat mode. It runs guided workflows bridged natively by `core/cli_bridge.py`. These workflows operate in a live Sohail-Agent execution/output area and rely on a shared, project-aware repository context:

- **Inspect**: Builds project context, identifies stacks, and detects frontend/backend components.
- **Dockerize**: Guided workflow to generate Docker configurations and manage Docker Compose handling.
- **Kubernetes**: Scaffolds Kubernetes deployment manifests.
- **CI/CD**: Generates continuous integration and continuous deployment pipelines based on project analysis.
- **Plan & Blueprint**: Automated planning capabilities and comprehensive implementation blueprints.

## Safety Rules & Separation

- **Strict Boundary**: There is complete architectural separation between the conversational Chat, the unrestricted Raw PTY Terminal, and the guided Sohail-Agent CLI workflows.
- **No Unrestricted Execution in Chat**: Chat cannot invoke unrestricted shell sessions or destructive tasks (e.g., `rm -rf`, `docker stop`, `git commit`).
- **Manual Approval Required**: All plans generated by the Sohail-Agent CLI require explicit manual user approval prior to execution.

## Limitations

- Only the `devops-qwen:latest` model is supported; external or cloud models are not integrated.
- The UI is designed solely for desktop resolutions; mobile layouts are unsupported.
- Advanced capabilities depend on the `Sohail-Agent-CLI` codebase, bounded tightly by `.venv/bin/sohail-agent`.

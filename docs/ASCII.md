LEFT PANEL — WORKSPACE INTELLIGENCE
==============================================================================================================

TOP
3D Engineering Knowledge Sphere

• Dark blue / cyan / purple nodes
• Slowly rotates
• Mouse drag rotates
• Mouse wheel zooms
• Click node to filter workspace
• Shows project technologies and relationships
• Completed work can become knowledge/session nodes

Example:
Docker • Kubernetes • Terraform • Python • FastAPI • React • Redis • PostgreSQL • Git • CI/CD


BOTTOM
AI Mentor

• Complete human AI engineer avatar
• Face + head + body + hands + legs
• Looks like a Senior Platform Engineer
• Gives proactive recommendations
• Does not behave only as a chatbot

Shows:
✓ What to do next
✓ Missing files
✓ Architecture suggestions
✓ Security warnings
✓ Performance suggestions
✓ Deployment advice
✓ Project summary
✓ Common mistakes

Example:

"I found a Dockerfile but no healthcheck."
